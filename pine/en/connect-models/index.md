# Connect models and services

Without a connected model Pine can't answer anything, so start with the first page. Web search and image/video generation are optional: if you only chat and work with files, you can skip them for now.

- [Connect a model: DeepSeek](deepseek.md): get an API key with DeepSeek as the example and enter it in Pine
- [Web search and fetching (TinyFish)](web-search.md): let Pine search and fetch web pages
- [Image and video generation, and automatic approval (OpenRouter)](media-generation.md): enable image generation, video generation, and the automatic-approval screening model

When that's done, continue with [Using Pine](../using-pine.md).
