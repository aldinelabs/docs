# Advanced configuration

[Using Pine](../using-pine.md) covers the basics of projects, sessions and approvals. These pages go through Pine's optional features and settings one by one: what each does, what it defaults to, and where to turn it on. None of them are required; look up a topic when you need it.

> [!NOTE]
> `Mod` means `Cmd` on macOS and `Ctrl` on Windows and Linux. Interface text follows Pine's English interface.

## Find by topic

- [Settings reference](settings.md): every option in the General, Appearance, Models, Agent, User profile, Multiple users, Projects and About sections of **Pine Settings**
- [Approvals and automatic review](approvals.md): the four approval modes, the automatic approval path, what an approval card shows, and which actions always ask you
- [Working with sessions](sessions.md): steering, quotes and follow-ups, attachments, interim answers, interactive answers, context and cost, sub-sessions, and letting the agent organize sessions and projects
- [Workbench and file previews](workbench.md): the workbench panels, file details, preview comments, the audio and video player, and enlarging images
- [Automations, Skills and MCP](automations.md): unattended automations, reusable Skills, and MCP servers that connect outside tools
- [Remote control](remote.md): Browser access, pairing a phone or other device through Aldine, keeping the computer awake, running in the background and the tray menu
- [WeChat remote](wechat.md): sending Pine tasks from your own WeChat, and every command available there
- [Keyboard shortcuts](shortcuts.md): every keyboard shortcut, including the composer and the quick composer

## Where the settings are

Click the gear in the title bar or press `Mod + ,` to open **Pine Settings**. The sections are listed on the left (on a phone, the list comes first):

| Section | Main contents | See |
| --- | --- | --- |
| **General** | Language, currency, guide buttons, one-time tips, completion signal, notifications, quick composer, running in the background, diagnostic logging | [Settings reference](settings.md) |
| **Appearance** | Color mode, default color theme, Working glow, sidebar material, Monet font, inverted documents | [Settings reference](settings.md) |
| **Models** | Model catalog refresh, Pi providers, title generation, approval, prompt optimization, live translation, image and video generation, Decisions screening model | [Settings reference](settings.md) |
| **Agent** | Behavior: Interactive answers, Interim answers, Reply suggestions, memory, approximate location, automatic approval path, context compaction; Tools: a switch for each tool family and the TinyFish key | [Settings reference](settings.md) |
| **User profile** | Aldine methodology, name and pronouns, communication style, technical background, work style, personal details, custom instructions | [Settings reference](settings.md) |
| **Multiple users** | Adding, switching and deleting users, and whether Pine asks who's using it at launch (desktop app only) | [Settings reference](settings.md) |
| **Projects** | Every project and its data usage; clearing temporary files and attachments | [Settings reference](settings.md) |
| **Remote control** | Keeping awake, pairing devices through Aldine, Browser access, WeChat | [Remote control](remote.md), [WeChat remote](wechat.md) |
| **About** | Version, Check for updates, links to the docs and source code, license and open-source software | [Settings reference](settings.md) |

Automations, Skills and MCP servers are not in the settings dialog but in the **More** menu at the top of the left sidebar; see [Automations, Skills and MCP](automations.md).
