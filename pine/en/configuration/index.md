# Advanced configuration

[Using Pine](../using-pine.md) covers the basics of projects, sessions and approvals. These pages go through Pine's optional features and settings one by one: what each does, what it defaults to, and where to turn it on. None of them are required; look up a topic when you need it.

> [!NOTE]
> `Mod` means `Cmd` on macOS and `Ctrl` on Windows. Interface text follows Pine's English interface.

## Find by topic

- [Settings reference](settings.md): every option in the General, Appearance, Models, Agent, User profile and Projects sections of **Pine Settings**
- [Approvals and automatic review](approvals.md): the four approval modes, the automatic approval path, what an approval card shows, and which actions always ask you
- [Working with sessions](sessions.md): steering, quotes and follow-ups, attachments, interim answers, interactive answers, context and cost, sub-sessions, and letting the agent organize sessions and projects
- [Workbench and file previews](workbench.md): the workbench panels, file details, preview comments, the audio and video player, and enlarging images
- [Automations, Skills and MCP](automations.md): unattended automations, reusable Skills, and MCP servers that connect outside tools
- [Remote control](remote.md): Browser access, pairing a phone or other device through Aldine, keeping the computer awake, running in the background and the tray menu
- [WeChat remote](wechat.md): sending Pine tasks from your own WeChat, and every command available there
- [Keyboard shortcuts](shortcuts.md): every keyboard shortcut

## Where the settings are

Click the gear in the title bar to open **Pine Settings**. The sections are listed on the left (on a phone, the list comes first):

| Section | Main contents | See |
| --- | --- | --- |
| **General** | Language, currency, Monet mode, completion signal, notifications, quick composer, running in the background, diagnostic logging | [Settings reference](settings.md) |
| **Appearance** | Color mode, default color theme, Working glow, sidebar material, inverted documents | [Settings reference](settings.md) |
| **Models** | Model catalog refresh, title generation, approval, image and video generation, Decisions screening model | [Settings reference](settings.md) |
| **Agent** | Interactive answers, Interim answers, automatic approval path, context compaction, web tools, approximate location | [Settings reference](settings.md) |
| **User profile** | Nickname, pronouns, communication style, technical background, personal details, custom instructions | [Settings reference](settings.md) |
| **Projects** | Every project and its data usage; clearing temporary files and attachments | [Settings reference](settings.md) |
| **Remote control** | Keeping awake, pairing devices through Aldine, Browser access, WeChat | [Remote control](remote.md), [WeChat remote](wechat.md) |

Automations, Skills and MCP servers are not in the settings dialog but in the **More** menu at the top of the left sidebar; see [Automations, Skills and MCP](automations.md).
