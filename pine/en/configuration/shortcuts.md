# Keyboard shortcuts

`Mod` means `Cmd` on macOS and `Ctrl` on Windows.

## Windows and tabs

| Shortcut | What it does |
| --- | --- |
| `Mod + N` / `Mod + T` | New session tab |
| `Mod + W` | Close tab (middle-clicking a tab also closes it) |
| `Mod + Shift + T` | Reopen the last closed tab |
| `Mod + Shift + N` | New window |
| `Mod + Shift + R` | Reload the window (plain `Mod + R` does nothing, so a stray press does not reload Pine) |
| `Mod + 1` … `Mod + 8` | Jump to that tab |
| `Mod + 9` | Jump to the last tab |
| `Mod + Alt + ←` / `→` | Previous / next tab |
| `Mod + B` | Show / hide the left sidebar |
| `Mod + Alt + B` | Show / hide the workbench |
| `Mod + L` | Focus the composer |

## Managers and search

| Shortcut | What it does |
| --- | --- |
| `Mod + K` | Search all sessions |
| `Mod + P` | Open **Pine Settings › Projects** |
| `Mod + S` | Skills manager |
| `Mod + U` | Automations manager |
| `Mod + /` | MCP servers manager |

The quick composer's global shortcut is set in **General**.

## Composer and approvals

| Shortcut | What it does |
| --- | --- |
| Enter | Send the message |
| `Shift + Enter` | New line |
| `Esc` | Return to the buttons from Reject with guidance |

With a session row focused in the left sidebar, `→` / `←` expand or collapse its sub-sessions.

## Enlarged images

After enlarging an image in a Markdown file's Rendered view:

| Shortcut | What it does |
| --- | --- |
| `←` / `→` | Previous / next image |
| `Mod + =` / `Mod + −` | Zoom in / out |
| `Mod + 0` | Fit to window |
| `Esc` | Close |

## Preview comments

| Shortcut | What it does |
| --- | --- |
| `Mod + Alt + M` | Comment on the selected text or cells |
| Enter / `Shift + Enter` | Save / new line in the comment box |
| `Esc` | Cancel the comment, or the area being drawn |

## Audio and video

While the preview is the active tab and focus is not in a text field:

| Shortcut | What it does |
| --- | --- |
| Space / `K` | Play / pause |
| `←` / `→` | Back / forward 5 seconds |
| `J` / `L` | Back / forward 10 seconds |
| `M` | Mute |
| `F` | Full screen (video) |
| `I` / `O` | Mark the start / end of a span to comment on |
| `Esc` | Clear the marks |
