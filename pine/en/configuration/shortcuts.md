# Keyboard shortcuts

`Mod` means `Cmd` on macOS and `Ctrl` on Windows and Linux. Holding `Mod` shows the shortcuts beside the controls they belong to.

## Windows and tabs

| Shortcut | What it does |
| --- | --- |
| `Mod + N` / `Mod + T` | New session tab |
| `Mod + W` | Close tab (middle-clicking a tab also closes it) |
| `Mod + Shift + W` | Close the window, the same as its close button |
| `Mod + Shift + T` | Reopen the last closed tab |
| `Mod + Shift + N` | New window |
| `Mod + Shift + R` | Reload the window (plain `Mod + R` never reloads Pine) |
| `Mod + 1` … `Mod + 8` | Jump to that tab |
| `Mod + 9` | Jump to the last tab |
| `Mod + Alt + ←` / `→` or `Mod + [` / `]` | Previous / next tab |
| `Mod + B` | Show / hide the left sidebar |
| `Mod + Alt + B` | Show / hide the workbench (does nothing while no tab is open) |
| `Mod + L` | Focus the composer |

## Managers and search

| Shortcut | What it does |
| --- | --- |
| `Mod + ,` | Open **Pine Settings** |
| `Mod + K` | Search all sessions |
| `Mod + P` | Open **Pine Settings › Projects** |
| `Mod + S` | Skills manager |
| `Mod + U` | Automations manager |
| `Mod + /` | MCP servers manager |

## Composer and approvals

| Shortcut | What it does |
| --- | --- |
| Enter | Send the message and scroll the conversation to it |
| `Alt + Enter` (`Option + Enter` on macOS) | Send the message without moving the conversation, so you can keep reading earlier parts |
| `Shift + Enter` | New line |
| `Mod + Enter` | Optimize prompt; `Esc` cancels it while it runs |
| `Mod + R` | Open the approval mode menu |
| `Mod + I` | Open the model menu |
| `Tab` / `→` | Use the reply suggestion shown in the composer |
| `↑` / `↓` | Show the previous / next reply suggestion in the empty composer |
| `Esc` | Return to the buttons from Reject with guidance |

`Mod + R` and `Mod + I` do nothing while another text field has focus.

## Quick composer

The quick composer's global shortcut is set in **General**. In the quick composer:

| Shortcut | What it does |
| --- | --- |
| Enter | Open the conversation in a window |
| `Control + Enter` (`Alt + Enter` on Windows and Linux) | Send in the background without bringing a window forward; a system notification tells you when the answer is ready |
| Backspace / `\` | Remove the captured context from an empty message |

With a session row focused in the left sidebar, `→` / `←` expand or collapse its sub-sessions.

## Guides and choosing a user

| Shortcut | What it does |
| --- | --- |
| `←` / `→` | Previous / next step in a guide |
| Arrow keys, Enter / Space | Move between users / open the focused user on "Who's using Pine?" |
| `1` … `9` | Open that user directly on "Who's using Pine?" |

## Enlarged images

After enlarging an image in a Markdown file's Rendered view:

| Shortcut | What it does |
| --- | --- |
| `←` / `→` | Previous / next image |
| `Mod + =` / `Mod + −` | Zoom in / out |
| `Mod + 0` | Fit to window |
| `Esc` | Close |

## Preview comments

| Shortcut | What it does |
| --- | --- |
| `Mod + Alt + M` | Comment on the selected text or cells |
| Enter / `Shift + Enter` | Save / new line in the comment box |
| `Esc` | Cancel the comment, or the area being drawn |

## Audio and video

While the preview is the active tab and focus is not in a text field:

| Shortcut | What it does |
| --- | --- |
| Space / `K` | Play / pause |
| `←` / `→` | Back / forward 5 seconds |
| `J` / `L` | Back / forward 10 seconds |
| `M` | Mute |
| `F` | Full screen (video) |
| `I` / `O` | Mark the start / end of a span to comment on |
| `Esc` | Clear the marks |
