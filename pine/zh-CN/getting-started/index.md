# 快速开始

这份指南写给**第一次安装 Pine 的普通用户**：不需要会写代码，按步骤做即可。如果你想在服务器上运行，或从源码构建，请看[进阶安装](../advanced/index.md)。

> [!CAUTION]
> Pine 目前是早期开发者预览版，界面、数据格式和 Agent 行为都可能发生不兼容变更。请不要把唯一一份重要文件交给它处理，先备份再使用。

这一组带你把 Pine 装好并启动：

- [开始之前](before-you-start.md)：支持的系统、需要准备的东西，以及数据与隐私
- [下载安装包](download.md)：用始终指向最新版本的直链，或从 GitHub Releases 下载
- [安装](install.md)：macOS 与 Windows 的安装步骤
- [首次启动](first-launch.md)：macOS 提示、Windows 沙箱配置和界面语言

装好之后，继续[连接模型与服务](../connect-models/index.md)。
