# 会话进阶

> [!TIP]
> 想看图解？侧栏 **更多功能（More）→ 指南（Guides）** 按主题列出所有图解教程。第一次遇到审批卡片、子会话、记忆、停止等功能时，旁边也会出现一条一次性提示，点 **看看教程（Show me）** 打开对应教程，点 **知道了（Got it）** 关掉。

## 与运行中的智能体协作

- **追加要求（Steer response）**：智能体工作时，在输入框输入新消息并选择追加要求，它会在下一步读到，不必中断任务。暂存的消息显示在输入框上方，每条下面有 **撤回（Withdraw）** 和 **立即发送（Send now）**。
- **停止回答（Stop response）**：随时中止本轮。已经做过的改动都会保留，还没完成的工具调用标为 **已停止（Stopped）**，接着说下一步就行。
- **编辑消息（Edit message）**：编辑自己发过的消息会从那里重新发送。
- **任务清单（Todos）**：智能体列出任务清单时，输入框上方显示进度卡片，点开是 **全部任务（All todos）**，带依赖关系图。全部完成后，卡片在本轮结束时消失。
- **后台进程（Background processes）**：智能体启动的长时间进程显示在卡片和工作台里，可查看命令、输出，或在运行中停止。
- **等待提示**：消息发出约 5 秒后仍没有任何回复、思考或工具调用时，回复位置会提示 Pine 仍在等待模型服务商响应；持续几十秒请检查网络和服务商是否可用。

## 输入框

- **发送**：回车发送消息，对话会滚到这条消息；`Alt + 回车` 发送但不移动对话位置，方便一边看前面的内容一边发消息。`Shift + 回车` 换行。
- **优化指令（Optimize prompt）**：写下要求后点 **优化指令** 或按 `Mod + 回车`，Pine 会把它改写成更清楚、具体的指令；只有你知道的信息会留成 `[[…]]` 空位，并自动选中第一个。改写时会参考项目、对话的开头和最近几轮、附件以及引用的内容。改写期间按 `Esc` 取消；完成后可以点 **撤销优化（Undo optimization）** 或按 `Mod + Z` 恢复原文。智能体工作时也能用，它会把你的插话改写成简短直接的纠正。改写用的模型在 **Pine 设置（Pine Settings）→ 模型（Models）→ 指令优化模型（Prompt optimization model）** 中选择。
- **回复建议（Reply suggestions）**：智能体回答完后，输入框里会淡入建议的下一句，一次最多三条，最可能的在前。按 `Tab`（光标在末尾时按 `→` 也可以）填入；在空输入框中按 `↑` / `↓` 切换，按键提示会显示当前是第几条（如 `Tab | 2/3 ↑↓`）。一开始输入建议就让位；没用上的建议会随对话保留，重新打开对话时仍在。可在 **Pine 设置（Pine Settings）→ 智能体（Agent）→ 行为（Behavior）** 中关闭。
- **滚动到底部（Scroll to bottom）**：在对话中往上翻得较远时，右下角会出现这个按钮，点击后回到最新内容并继续跟随回复。

## 引用、追问与侧边对话

在对话中选中一段文字，会出现两个按钮：

- **引用（Quote）**：把这段文字作为引用附到下一条消息。
- **追问（Follow up）**：在工作台打开一个针对这段文字的侧边对话。追问随会话保存，原文会被高亮，点击高亮可以重新打开。

**侧边对话（Side chat）** 是关于当前会话的只读对话：它能读文件、搜索网页，但不能改动任何东西，适合在不打扰主线任务的情况下问问题。从工作台的面板切换器或 **添加卡片（Add card）** 打开的整段侧边对话标着 **不保存（Not saved）**，关闭后即丢弃。

长会话可以用 **对话大纲（Conversation outline）** 快速跳到之前的某一轮。

## 附件

点输入框的 **添加附件（Add attachment）** 可以添加 **文件（File）**、**文件夹（Folder）** 或 **会话（Conversation）**；也可以直接拖入文件、粘贴图片和长文本。

- **附加会话**：从左侧栏把一个会话拖进输入框，或在附件菜单中选择会话。智能体会读取那段对话，不需要审批。发出后点击会话附件可以打开它。
- **从文件预览发送**：文件预览里的 **发送到选项卡…（Send to tab…）** 和 **发送选中范围到选项卡…（Send selection to tab…）** 把整个文件或选中内容附到某个会话；预览批注也能一次发到会话，见[工作台与文件预览](workbench.md)。
- 在没有项目的新会话中输入 `@` 可以选择项目。

## 回答的形式

- **交互式回答（Interactive answers）**：回复里可以出现可勾选的清单、表格、图表、计算器、表单、日期选择器、倒计时、时间线、公式、带复制按钮的代码、折叠面板、轮播、步骤和可翻面的卡片等，智能体也会用图片展示截图和生成结果。可在 **Pine 设置（Pine Settings）→ 智能体（Agent）→ 行为（Behavior）** 中关闭。
- **中途回答（Interim answers）**：智能体可以在耗时操作（例如网页搜索）前先给出初步答复，或在多部分问题中解决一部分就回复一部分，然后继续工作。它和普通回复一样可以选中、引用、搜索和导出。可在同一位置关闭。
- **提问卡片**：智能体需要你补充信息时，输入框位置会出现问题卡片，可以用 **上一题（Previous）** / **下一题（Next）** 切换，也可以填写自由文本后 **提交（Submit）**。
- **工具调用详情（Tool call details）**：点击对话中的工具调用，可以查看它的状态、审批、参数和结果。参数，以及本身是 JSON 的结果，显示为带缩进和语法高亮的 JSON，长文本自动换行；普通文本和 Markdown 结果照常显示。被审批模型或沙盒拦下的调用旁有 **为什么被拦下？（Why was this blocked?）**，打开讲解原因的教程。

## 上下文与费用

输入框底部的 **上下文占用（Context usage）** 显示上下文的占用比例，模型有定价时还会显示这次对话目前的花费（如 `10%  ¥0.63`），按 **通用（General）** 中选的货币显示。点开它：

- 上半部分显示已用 token、上下文窗口、占用比例和缓存命中率，**立即压缩上下文（Compact context now）** 手动压缩。自动压缩的策略在[设置详解](settings.md)中配置。
- 下半部分显示本会话的费用，以及 **会话成本上限（Session cost limit）** 开关和金额。达到上限会停止运行，并阻止发送新消息，直到你提高或取消上限；提示里的 **了解原因（Learn why）** 会打开讲解费用的教程。可以在会话开始前就设好。
- 最上方的 **上下文是怎么回事（How context works）** 打开讲解上下文和 token 的图解教程。

输入框底部还可以切换本会话的 **模型（Model）**（`Mod + I`）和 **推理强度（Reasoning effort）**。窗口较窄时，费用、推理强度和占用比例会依次收起，仍可以在弹出框和模型菜单中看到。

## 记忆

Pine 能跨会话记住事情。让它“记住”某件事，或者它在工作中了解到你的偏好、做过的决定和踩过的坑时，会存成一条记忆，之后的新会话开始时就带着这些记忆。记忆分为只在当前项目生效和在所有项目生效两种，只保存在本机。Pine 只记对以后其他对话有用的内容，并合并到已有的记忆里，不会重复保存；保存、读取、修改或删除记忆时，对话中会显示单独的条目，写明对应的记忆。

- **管理记忆**：在侧栏 **更多功能（More）→ 记忆（Memory）** 中，按 **本项目（This project）** 和 **所有项目（All projects）** 查看记忆。每条显示名称和一句话摘要，Pine 还没确认的带 **未验证（Unverified）** 标记。点 **编辑（Edit）** 可以修改 **摘要（Summary）** 和 **详细内容（Details）**、打开 **已验证（Verified）**，或删除这条记忆。标题旁的 **记忆怎么用（How memory works）** 打开图解教程。
- **关闭记忆**：**Pine 设置（Pine Settings）→ 智能体（Agent）→ 行为（Behavior）** 中的 **跨会话记忆（Remember across sessions）** 默认开启，关闭后 Pine 不再读取或保存记忆，已有的记忆仍可以在记忆窗口里管理。自动化运行不读取也不保存记忆。

## 子会话与智能体开启的会话

你可以让智能体开启新的会话去处理相互独立的工作：

- **子会话**：通常的选择。它属于当前会话，在左侧栏缩进显示在父会话下方，用连线相连；父会话行尾的箭头可以展开或收起（也可以再次点击已打开的父会话那一行）。子会话的标签页图标是两个对话气泡。子会话只有一层，它自己只能开同级会话。
- **同级会话**：在当前项目或其他项目里开启的独立会话，在后台工作，出现在左侧栏，不会打开标签页或切走你当前的会话。

想让新会话用更轻快或别的模型，直接告诉智能体，它会从你设置好的模型里为新会话选好模型和推理强度，新会话的模型菜单会显示所选模型，你也可以随时改；没有特别要求时，新会话使用你的默认模型。

子会话完成一轮、失败或等待审批时，父会话里会出现一条标记（例如“子会话 {名称} 已完成”），点击即可打开；父会话的智能体会读取子会话的回复并继续工作，即使父会话没有打开标签页。子会话的审批要在它自己的标签页里处理。你在子会话里按停止后，父会话显示“你停止了子会话 {名称}”，它不会自行接着做，而是先问你要继续、换个方向、自己接手还是放弃。一个会话发给另一个会话的消息，会在接收方显示“由 {名称} 创建”或“来自 {名称}”，点击可以打开发送方。

智能体可以读取子会话和同级会话的消息并给它们发消息，也可以搜索你所有项目里的会话。读取与当前工作无关的会话前需要经过审核：让我过目模式下弹出卡片，自动审批和自主工作模式下由审批模型审核，干就完了模式下不审核。它也能给这些会话发消息，每条消息都按同样的方式审核；你发的消息明显属于另一个会话时，它会转过去，并告诉你转到了哪里。

智能体还可以像 **停止回答** 按钮那样结束另一个会话当前的这一轮，那个会话仍留在侧栏中，之后可以继续发消息。停止它自己开的子会话不需要审批，停止其他会话会先按同样的方式审核。

## 让智能体整理会话和项目

只要你开口，智能体可以：

- **整理会话**：新建、重命名、删除会话文件夹，把会话移入或移出文件夹，重命名会话。删除会话始终需要你确认。
- **管理项目**：用文件夹新建项目，重命名项目，增删文件夹，更换工作文件夹，设置图标和强调色，或删除项目。每一项改动在任何模式下都需要你确认。删除项目会删除它的会话，但保留磁盘上的文件夹；智能体不能删除自己所在的项目、**无项目（No Project）**，或仍有会话在运行的项目。

**会话标题**：Pine 在第一轮对话后为会话起标题；之后的消息开始了另一项任务时，智能体可能把标题更新为当前在做的事。你用重命名改过的标题不会被悄悄替换：智能体想换标题时，会在对话末尾提出建议（“将此会话重命名为“…”？”），可以选择 **重命名（Rename）**、**暂不（Not now）** 或 **不再建议（Don't suggest again）**。

## 管理会话

- **搜索会话**：`Mod + K` 搜索所有项目的会话标题和内容。
- **会话文件夹**：在项目分组标题的按钮上新建文件夹；右键文件夹可以 **重命名文件夹（Rename folder）** 或 **删除文件夹（Delete folder）**（其中的会话会回到项目下）。
- **右键会话**：**重命名（Rename conversation）**、**导出（Export conversation）**（Markdown）、**移动到文件夹（Move to folder）**、**删除（Delete conversation）**（永久删除）。
- **会话状态**：左侧栏会话标题左侧显示状态：等你批准或回答时是一个呼吸的琥珀色圆点（“等待你批准”“等待你回答”），运行中是一个小转圈，你没看到就结束的运行是一个强调色圆点（“未读”，打开会话后消失，重启后仍保留）。运行中的会话标题还会闪烁；自动化运行带工作流图标；从微信发起或使用过的会话带对话气泡图标。
- **标签页**：标签页按标题长短调整宽度，放不下的标题在末尾淡出，关闭按钮在悬停时覆盖在标题末尾；空间不够时其他标签页先缩到最窄，然后才横向滚动。`Mod + [` 和 `Mod + ]` 切换到上一个和下一个标签页。
