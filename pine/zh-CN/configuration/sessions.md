# 会话进阶

## 与运行中的智能体协作

- **追加要求（Steer response）**：智能体工作时，在输入框输入新消息并选择追加要求，它会在下一步读到，不必中断任务。暂存的消息显示在输入框上方，每条下面有 **撤回（Withdraw）** 和 **立即发送（Send now）**。
- **停止回答（Stop response）**：随时中止本轮。
- **编辑消息（Edit message）**：编辑自己发过的消息会从那里重新发送。
- **任务清单（Todos）**：智能体列出任务清单时，输入框上方显示进度卡片，点开是 **全部任务（All todos）**，带依赖关系图。全部完成后，卡片在本轮结束时消失。
- **后台进程（Background processes）**：智能体启动的长时间进程显示在卡片和工作台里，可查看命令、输出，或在运行中停止。
- **等待提示**：消息发出约 3 秒后仍没有任何回复、思考或工具调用时，回复位置会提示 Pine 仍在等待模型服务商响应；持续几十秒请检查网络和服务商是否可用。

## 引用、追问与侧边对话

在对话中选中一段文字，会出现两个按钮：

- **引用（Quote）**：把这段文字作为引用附到下一条消息。
- **追问（Follow up）**：在工作台打开一个针对这段文字的侧边对话。追问随会话保存，原文会被高亮，点击高亮可以重新打开。

**侧边对话（Side chat）** 是关于当前会话的只读对话：它能读文件、搜索网页，但不能改动任何东西，适合在不打扰主线任务的情况下问问题。从工作台的面板切换器或 **添加卡片（Add card）** 打开的整段侧边对话标着 **不保存（Not saved）**，关闭后即丢弃。

长会话可以用 **对话大纲（Conversation outline）** 快速跳到之前的某一轮。

## 附件

点输入框的 **添加附件（Add attachment）** 可以添加 **文件（File）**、**文件夹（Folder）** 或 **会话（Conversation）**；也可以直接拖入文件、粘贴图片和长文本。

- **附加会话**：从左侧栏把一个会话拖进输入框，或在附件菜单中选择会话。智能体会读取那段对话，不需要审批。发出后点击会话附件可以打开它。
- **从文件预览发送**：文件预览里的 **发送到选项卡…（Send to tab…）** 和 **发送选中范围到选项卡…（Send selection to tab…）** 把整个文件或选中内容附到某个会话；预览批注也能一次发到会话，见[工作台与文件预览](workbench.md)。
- 在没有项目的新会话中输入 `@` 可以选择项目。

## 回答的形式

- **交互式回答（Interactive answers）**：回复里可以出现可勾选的清单、表格、图表、计算器和输入框。可在 **Pine 设置（Pine Settings）→ 智能体（Agent）** 中关闭。
- **中途回答（Interim answers）**：智能体可以在耗时操作（例如网页搜索）前先给出初步答复，或在多部分问题中解决一部分就回复一部分，然后继续工作。它和普通回复一样可以选中、引用、搜索和导出。可在同一位置关闭。
- **提问卡片**：智能体需要你补充信息时，输入框位置会出现问题卡片，可以用 **上一题（Previous）** / **下一题（Next）** 切换，也可以填写自由文本后 **提交（Submit）**。

## 上下文与费用

点输入框底部的 **上下文占用（Context usage）**：

- 上半部分显示已用 token、上下文窗口、占用比例和缓存命中率，**立即压缩上下文（Compact context now）** 手动压缩。自动压缩的策略在[设置详解](settings.md)中配置。
- 下半部分显示本会话的费用（货币在 **通用（General）** 中设置），以及 **会话成本上限（Session cost limit）** 开关和金额。达到上限会停止运行，并阻止发送新消息，直到你提高或取消上限。可以在会话开始前就设好。

输入框底部还可以切换本会话的 **模型（Model）** 和 **推理强度（Reasoning effort）**。

## 子会话与智能体开启的会话

你可以让智能体开启新的会话去处理相互独立的工作：

- **子会话**：通常的选择。它属于当前会话，在左侧栏缩进显示在父会话下方，用连线相连；父会话行尾的箭头可以展开或收起（也可以再次点击已打开的父会话那一行）。子会话的标签页图标是两个对话气泡。子会话只有一层，它自己只能开同级会话。
- **同级会话**：在当前项目或其他项目里开启的独立会话，在后台工作，出现在左侧栏，不会打开标签页或切走你当前的会话。

子会话完成一轮、失败或等待审批时，父会话里会出现一条标记（例如“子会话 {名称} 已完成”），点击即可打开；父会话的智能体会读取子会话的回复并继续工作，即使父会话没有打开标签页。子会话的审批要在它自己的标签页里处理。一个会话发给另一个会话的消息，会在接收方显示“由 {名称} 创建”或“来自 {名称}”，点击可以打开发送方。

智能体还可以搜索你所有项目里的会话。读取与当前工作无关的会话前需要经过审核：让我过目模式下弹出卡片，自动审批和自主工作模式下由审批模型审核，干就完了模式下不审核。它不能给这些会话发消息。

## 让智能体整理会话和项目

只要你开口，智能体可以：

- **整理会话**：新建、重命名、删除会话文件夹，把会话移入或移出文件夹，重命名会话。删除会话始终需要你确认。
- **管理项目**：用文件夹新建项目，重命名项目，增删文件夹，更换工作文件夹，设置图标和强调色，或删除项目。每一项改动在任何模式下都需要你确认。删除项目会删除它的会话，但保留磁盘上的文件夹；智能体不能删除自己所在的项目、**无项目（No Project）**，或仍有会话在运行的项目。

**会话标题**：Pine 在第一轮对话后为会话起标题；之后的消息开始了另一项任务时，智能体可能把标题更新为当前在做的事。你用重命名改过的标题会一直保留，直到你再次修改。

## 管理会话

- **搜索会话**：`Mod + K` 搜索所有项目的会话标题和内容。
- **会话文件夹**：在项目分组标题的按钮上新建文件夹；右键文件夹可以 **重命名文件夹（Rename folder）** 或 **删除文件夹（Delete folder）**（其中的会话会回到项目下）。
- **右键会话**：**重命名（Rename conversation）**、**导出（Export conversation）**（Markdown）、**移动到文件夹（Move to folder）**、**删除（Delete conversation）**（永久删除）。
- 左侧栏里，运行中的会话标题会闪烁；停在审批上的会话行尾有盾牌图标（“等待你批准”）；自动化运行带工作流图标；从微信发起或使用过的会话带对话气泡图标。
