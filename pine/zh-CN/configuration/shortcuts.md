# 快捷键

`Mod` 在 macOS 上是 `Cmd`，在 Windows 和 Linux 上是 `Ctrl`。按住 `Mod` 时，界面上会在相应控件旁显示它们的快捷键。

## 窗口与标签页

| 快捷键 | 作用 |
| --- | --- |
| `Mod + N` / `Mod + T` | 新建会话标签 |
| `Mod + W` | 关闭标签（中键点击标签也可以关闭） |
| `Mod + Shift + W` | 关闭窗口，与窗口的关闭按钮相同 |
| `Mod + Shift + T` | 重新打开刚关闭的标签 |
| `Mod + Shift + N` | 新建窗口 |
| `Mod + Shift + R` | 重新加载窗口（单按 `Mod + R` 不会重新加载 Pine） |
| `Mod + 1` … `Mod + 8` | 跳到对应位置的标签 |
| `Mod + 9` | 跳到最后一个标签 |
| `Mod + Alt + ←` / `→` 或 `Mod + [` / `]` | 上一个 / 下一个标签 |
| `Mod + B` | 显示 / 隐藏左侧栏 |
| `Mod + Alt + B` | 显示 / 隐藏右侧工作台（没有打开任何标签时无效） |
| `Mod + L` | 聚焦输入框 |

## 管理器与搜索

| 快捷键 | 作用 |
| --- | --- |
| `Mod + ,` | 打开 **Pine 设置（Pine Settings）** |
| `Mod + K` | 搜索所有会话 |
| `Mod + P` | 打开 **Pine 设置 → 项目管理（Projects）** |
| `Mod + S` | Skills 管理器 |
| `Mod + U` | 自动化管理器 |
| `Mod + /` | MCP 服务器管理器 |

## 输入框与审批

| 快捷键 | 作用 |
| --- | --- |
| 回车 | 发送消息，并把对话滚动到新消息 |
| `Alt + 回车`（macOS 上是 `Option + 回车`） | 发送消息，但不移动对话，方便继续阅读前面的内容 |
| `Shift + 回车` | 换行 |
| `Mod + 回车` | 优化指令（Optimize prompt）；运行时按 `Esc` 取消 |
| `Mod + R` | 打开审批模式菜单 |
| `Mod + I` | 打开模型菜单 |
| `Tab` / `→` | 采用输入框里显示的回复建议 |
| `↑` / `↓` | 在空输入框中切换到上一条 / 下一条回复建议 |
| `Esc` | 在“拒绝并说明要求”中返回按钮 |

`Mod + R` 和 `Mod + I` 在其他文本框中不生效。

## 快速提问

快速提问（Quick composer）的全局快捷键在 **通用（General）** 中自行设置。在快速提问窗口里：

| 快捷键 | 作用 |
| --- | --- |
| 回车 | 在窗口中打开这段对话 |
| `Control + 回车`（Windows 和 Linux 上是 `Alt + 回车`） | 在后台发送，不调出窗口，回答好了用系统通知告诉你 |
| 退格 / `\` | 在空消息中去掉截取的上下文 |

左侧栏中某个会话行获得焦点时，`→` / `←` 展开或收起它的子会话。

## 图解教程与用户选择

| 快捷键 | 作用 |
| --- | --- |
| `←` / `→` | 图解教程中的上一步 / 下一步 |
| 方向键、回车 / 空格 | 在“谁在使用 Pine？”中切换用户 / 打开选中的用户 |
| `1` … `9` | 在“谁在使用 Pine？”中直接打开对应的用户 |

## 图片查看

在 Markdown 渲染视图中放大图片后：

| 快捷键 | 作用 |
| --- | --- |
| `←` / `→` | 上一张 / 下一张 |
| `Mod + =` / `Mod + −` | 放大 / 缩小 |
| `Mod + 0` | 适合窗口 |
| `Esc` | 关闭 |

## 预览批注

| 快捷键 | 作用 |
| --- | --- |
| `Mod + Alt + M` | 批注选中的文字或单元格 |
| 回车 / `Shift + 回车` | 批注框中保存 / 换行 |
| `Esc` | 取消批注，或取消正在框选的区域 |

## 音视频播放

预览是当前标签、且焦点不在文本框中时可用：

| 快捷键 | 作用 |
| --- | --- |
| 空格 / `K` | 播放 / 暂停 |
| `←` / `→` | 后退 / 前进 5 秒 |
| `J` / `L` | 后退 / 前进 10 秒 |
| `M` | 静音 |
| `F` | 全屏（视频） |
| `I` / `O` | 标记要批注的时间段起点 / 终点 |
| `Esc` | 清除标记 |
