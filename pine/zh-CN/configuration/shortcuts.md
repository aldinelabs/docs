# 快捷键

`Mod` 在 macOS 上是 `Cmd`，在 Windows 上是 `Ctrl`。

## 窗口与标签页

| 快捷键 | 作用 |
| --- | --- |
| `Mod + N` / `Mod + T` | 新建会话标签 |
| `Mod + W` | 关闭标签（中键点击标签也可以关闭） |
| `Mod + Shift + T` | 重新打开刚关闭的标签 |
| `Mod + Shift + N` | 新建窗口 |
| `Mod + Shift + R` | 重新加载窗口（单按 `Mod + R` 不会重新加载，以免误触） |
| `Mod + 1` … `Mod + 8` | 跳到对应位置的标签 |
| `Mod + 9` | 跳到最后一个标签 |
| `Mod + Alt + ←` / `→` | 上一个 / 下一个标签 |
| `Mod + B` | 显示 / 隐藏左侧栏 |
| `Mod + Alt + B` | 显示 / 隐藏右侧工作台 |
| `Mod + L` | 聚焦输入框 |

## 管理器与搜索

| 快捷键 | 作用 |
| --- | --- |
| `Mod + K` | 搜索所有会话 |
| `Mod + P` | 打开 **Pine 设置 → 项目管理（Projects）** |
| `Mod + S` | Skills 管理器 |
| `Mod + U` | 自动化管理器 |
| `Mod + /` | MCP 服务器管理器 |

快速提问（Quick composer）的全局快捷键在 **通用（General）** 中自行设置。

## 输入框与审批

| 快捷键 | 作用 |
| --- | --- |
| 回车 | 发送消息 |
| `Shift + 回车` | 换行 |
| `Esc` | 在“拒绝并说明要求”中返回按钮 |

左侧栏中某个会话行获得焦点时，`→` / `←` 展开或收起它的子会话。

## 图片查看

在 Markdown 渲染视图中放大图片后：

| 快捷键 | 作用 |
| --- | --- |
| `←` / `→` | 上一张 / 下一张 |
| `Mod + =` / `Mod + −` | 放大 / 缩小 |
| `Mod + 0` | 适合窗口 |
| `Esc` | 关闭 |

## 预览批注

| 快捷键 | 作用 |
| --- | --- |
| `Mod + Alt + M` | 批注选中的文字或单元格 |
| 回车 / `Shift + 回车` | 批注框中保存 / 换行 |
| `Esc` | 取消批注，或取消正在框选的区域 |

## 音视频播放

预览是当前标签、且焦点不在文本框中时可用：

| 快捷键 | 作用 |
| --- | --- |
| 空格 / `K` | 播放 / 暂停 |
| `←` / `→` | 后退 / 前进 5 秒 |
| `J` / `L` | 后退 / 前进 10 秒 |
| `M` | 静音 |
| `F` | 全屏（视频） |
| `I` / `O` | 标记要批注的时间段起点 / 终点 |
| `Esc` | 清除标记 |
