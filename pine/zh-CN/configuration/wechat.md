# 微信远程

**微信远程**（实验性）让你用自己的微信，通过腾讯 ClawBot 给这台电脑上的 Pine 发任务、看进度、处理审批和取回文件。设置在 **Pine 设置（Pine Settings）→ 远程控制（Remote control）→ 微信（WeChat）**。

> [!WARNING]
> 微信远程开启后，能进入你微信账号的人就能指挥这台电脑上的 Pine。消息会经过腾讯的服务器；已连接的账号可以读取所有项目的会话标题、搜索结果和回复。请按下面的说明设好权限边界。

## 连接微信

1. 点 **连接微信（Connect WeChat）**，用手机微信扫描对话框里的二维码，并在手机上确认。如果微信要求，再输入手机上显示的验证码。
2. 在微信里给机器人发任意一条消息（一个句点就行），它会回复一个 6 位配对码。
3. 把配对码填进对话框的六个格子（可以直接粘贴），填满即自动提交。配对码过期后点 **重试（Try again）**。

连接后，设置里显示 **微信账号 XXXX-XXXX** 和状态：**在线（Online）**、**正在连接（Connecting）**、**正在重试（Retrying）**、**需要重新扫码（Scan again needed）** 或 **已暂停（Paused）**。需要重新扫码时点 **重新扫码（Scan again）**。

一个微信账号只能连接一台电脑。使用代理或境外网络出口时，连接可能被拦截。

## 权限设置

| 选项 | 说明 |
| --- | --- |
| **接收来自微信的任务（Receive tasks from WeChat）** | 关闭后 Pine 忽略微信消息。只能在这台电脑上重新打开 |
| **默认项目（Default project）** | 从微信新建的会话放在哪个项目，或 **无项目（No Project）** |
| **最高审批模式（Highest approval mode）** | 微信驱动的会话不会以比它更宽松的模式运行。选择 **干就完了（YOLO）** 前会再次确认 |
| **默认审批模式（Default approval mode）** | 从微信新建会话时使用的模式，只能在最高审批模式以内 |
| **允许在微信中批准高风险操作（Allow approving high-risk actions from WeChat）** | 沙箱之外的原生执行和破坏性命令。默认关闭，此时这类操作只能在电脑上批准 |
| **允许向微信发送文件（Allow sending files to WeChat）** | 只发送会话的产出文件（智能体提交的结果），每个最多 100 MB。默认关闭。开启后，一次任务提交或打开的文件最多前三个会紧跟结果发出，其余用 `.o` 查看 |

**断开（Disconnect）** 会先确认：只由微信持有的会话会停止，微信相关的权限设置恢复默认。

微信驱动的会话所开启或联系的其他会话，也受同样的上限约束。自动化的审批无论从哪里发起，都只能在电脑上处理。

## 在微信里使用

- **普通文字**发给当前会话。想在智能体运行时补充要求，用 `.queue` 把文字排进插话队列，它会在下一步读到。
- **命令**以句点开头（`.` 或中文句号 `。` 都可以），发送 `.help`（或 `.?`）查看常用命令，`.h 2` 查看其余命令。
- 回复以 Markdown 排版，列表和命令帮助以窄表格显示；回复过长时会截断，并提示如何查看全文。
- 审批卡片和问题卡片带编号，发送 `.编号` 查看完整卡片；交互式回答的按钮也有编号，直接回复数字作答。
- 发出超过 10 分钟才到达 Pine 的任务，会等你在微信里确认后才执行。

## 通知与托盘

即使关闭了通知，下列事件也一定会弹出系统通知：从微信新建会话、首次从微信使用已有会话、从微信批准高风险操作、向微信发送文件、从微信删除会话、从微信运行自动化、从微信把会话切到干就完了模式、需要重新扫码、微信远程被暂停或设置被重置。点击通知会把 Pine 窗口带到前台。

托盘菜单的 **微信远程（WeChat remote）** 开关可以随时暂停或恢复接收，作用与设置里的 **接收来自微信的任务** 相同。微信远程正在接收时退出 Pine 会再次确认，退出后将收不到从微信发来的任务。想让它长期在线，可以[在服务器上运行](../advanced/server.md) Pine。
