# 工作台与文件预览

## 工作台

工作台是窗口右侧的面板（`Mod + Alt + B` 显示或隐藏），每个会话各有一份。它最多上下放两张卡片，中间的把手可以调整高低，左边缘可以拖动调整宽度。每张卡片标题栏有面板切换器、**在标签页中打开（Open in tab）**、**添加卡片（Add card）** 和关闭按钮。

| 面板 | 内容 |
| --- | --- |
| **产出文件（Artifacts）** | 本会话的交付成果：智能体明确提交的结果文件，最新的在前，带标题和一句话说明。只用来展示进度或对比的文件不在这里 |
| **后台进程（Background processes）** | 智能体启动的进程及其输出 |
| **预览（Preview）** | 智能体最近展示的文件，或从产出文件里选中的文件 |
| **文件（Files）** | 项目的文件树，显示各文件夹的访问权限 |
| **侧边对话（Side chat）** | 关于当前会话的只读对话，见[会话进阶](sessions.md) |

智能体打开某张卡片或在预览中展示文件时，那张卡片会以黄色闪烁，直到你把鼠标移上去。智能体全屏展示的文件会在当前标签后面打开一个闪烁的标签页，不会抢走焦点。

## 文件预览

在文件树、会话或产出文件中点击文件，会以标签页打开预览。根据格式不同，预览提供 **渲染（Rendered）** / **文本（Text）** 视图、翻页、搜索、缩放、旋转、反色、工作表和图层切换，以及 **用默认应用打开（Open with default application）**。

### 详细信息与批注卡片

文件标签页在前台时，右侧栏不显示会话的卡片，而是显示这个文件的两张卡片：上方 **详细信息（Details）**，下方 **批注（Comments）**（仅限可以批注的项目文件）。右侧栏默认关闭，用预览底部的 **批注** 按钮（不能批注的文件显示为 **详细信息**）、标题栏的工作台按钮或 `Mod + Alt + B` 打开。

**详细信息** 列出类型、大小、修改和创建时间、位置，以及预览测得的编码、行数、尺寸、时长、页数、行列数，还有格式本身记录的信息，例如文档的标题、作者、应用和字数，照片的相机、拍摄时间和色彩模式，音视频的编码和标签，邮件的发件人和收件人，压缩包的条目。

### Markdown 图片查看

在 Markdown 文件的渲染视图中点击图片（或聚焦后按回车），窗口变模糊，图片放大到窗口中央。底部工具栏可以切换上一张 / 下一张、**适合窗口（Fit to window）**、缩小和放大；`Mod + 滚轮` 也能缩放，放大后可以拖动查看。点图片外面、关闭按钮或按 `Esc` 返回。

### 音视频播放器

音频和视频用 Pine 自己的播放器播放：进度条（点击或拖动跳转）、播放 / 暂停、当前时间和总长、**评论此刻（Comment on this moment）**、**循环播放（Loop）**、**播放速度（Playback speed）**、静音和音量，视频还有 **画中画（Picture in picture）** 和全屏。快捷键见[快捷键](shortcuts.md)。

## 预览批注

在项目文件的预览里，可以对文件的某些部分写下修改意见，攒够了再一次发给会话。

### 能批注什么

| 方式 | 适用格式 |
| --- | --- |
| 选中文字 | 文本、代码、Markdown（文本或渲染视图）、HTML、Word 等文档（DOCX、DOC、ODT、RTF、Pages）、PDF、幻灯片（PPTX、PPT、Keynote）、EPUB 电子书、邮件（EML、MSG） |
| 选中单元格 | 电子表格（XLSX、Numbers）、CSV / TSV 等数据表、SQLite 表 |
| 框选区域 | 图片、PDF 页面、幻灯片、PSD、OFD、Typst、PostScript、draw.io、Mermaid 等图表、思维导图 |
| 时间段 | 音频和视频 |

### 怎么批注

- **文字和单元格**：选中后在浮动菜单中点 **批注（Comment）**，或按 `Mod + Alt + M`，输入意见。回车保存，`Shift + 回车` 换行，`Esc` 取消。
- **区域**：点预览底部的 **框选批注（Comment on area）**，在图片、页面或幻灯片上拖出一个框，`Esc` 取消。
- **时间段**：播放器里点 **评论此刻** 批注当前时间点；按住 `Shift` 在进度条上拖动，或在起点按 `I`、终点按 `O`，标出一段时间再批注。

批注过的文字以琥珀色高亮，单元格和区域以琥珀色框出，点击即可在右侧栏定位到那条批注。

### 管理和发送

- **批注** 卡片按文档顺序列出所有批注，每条显示位置（如“第 12 行”、“第 3 页”、“B2:D5”、“0:12–0:30”）、引用的原文和意见，可以编辑或删除。原文在文件改动后不复存在时，会标记为“原文已变化（Original text changed）”。
- 卡片底部的 **发送 N 条批注（Send N comments）** 列出项目里的会话标签页和新会话。选一个，批注就以批注附件的形式（文件、位置和意见）放进那个会话的输入框，并从预览中清除。
- **全部清除（Clear all）** 会先确认再删除。

> [!NOTE]
> 每个文件最多 50 条批注。批注只保存在内存中，发送或清除前一直有效，退出 Pine 后不会保留。
