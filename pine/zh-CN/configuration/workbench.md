# 工作台与文件预览

## 工作台

工作台是窗口右侧的面板（`Mod + Alt + B` 显示或隐藏），每个会话各有一份。它最多上下放两张卡片，中间的把手可以调整高低，左边缘可以拖动调整宽度。每张卡片标题栏有面板切换器、**在标签页中打开（Open in tab）**、**添加卡片（Add card）** 和关闭按钮。关闭最后一个标签页时工作台随之关闭，再打开一个标签页就能重新使用。

| 面板 | 内容 |
| --- | --- |
| **产出文件（Artifacts）** | 本会话的交付成果：智能体明确提交的结果文件，最新的在前，带标题和一句话说明，可以按文件夹整理，并保留每次提交的版本（见下文）。只用来展示进度或对比的文件不在这里 |
| **后台进程（Background processes）** | 智能体启动的进程及其输出 |
| **预览（Preview）** | 智能体最近展示的文件，或从产出文件里选中的文件 |
| **文件（Files）** | 项目的文件树，显示各文件夹的访问权限 |
| **实时上下文（Live context）** | Beta，macOS 26 或更高版本。把会议或课堂转写成当前对话的上下文，见下文 |
| **侧边对话（Side chat）** | 关于当前会话的只读对话，见[会话进阶](sessions.md) |

智能体打开某张卡片或在预览中展示文件时，那张卡片会以黄色闪烁，直到你把鼠标移上去。智能体全屏展示的文件会在当前标签后面打开一个闪烁的标签页，不会抢走焦点。

侧栏 **更多功能（More）→ 指南（Guides）** 中的“工作台”教程用图解介绍各个面板，以及产出文件的文件夹、版本和拖出。

## 产出文件

- **文件夹**：文件较多时，智能体会把产出文件放进文件夹（例如“报告 › 第 1 周”），列表显示为可折叠的文件夹树，展开状态按会话记住。文件夹只用于整理列表，不会移动磁盘上的文件；想换一种分法，直接告诉 Pine 就行。
- **拖出去**：列表中的文件可以拖到输入框、文件树，或拖到桌面、访达和其他应用。
- **版本**：智能体每次提交文件时，Pine 会按提交时的样子保留一份副本（单个文件不超过 25 MB；每个项目最多保留 1 GB，超出时先删除最旧的）。有多个版本的文件带时钟标记和版本数；右键文件选 **版本历史（Version history）** 可以直接查看。点击对话中提交的文件，会打开它提交时的样子。

### 浏览、对比和恢复版本

**预览** 卡片的标题栏，以及从产出文件打开的文件标签页底栏，都有 **版本历史（Version history）** 菜单：最上面是 **当前文件（Current file）**，下面按时间列出保留的版本，带智能体对那次提交的说明和大小，与磁盘上文件一致的那个标着 **当前（Current）**。

选中一个版本后，它会以只读方式打开，顶部一栏可以：

- 打开 **与当前文件对比（Compare with current）**，查看从这个版本到当前文件的改动。Markdown 文件按渲染后的样子对比，新增和删除的段落带底色，改动的词语会标出；在文件标签页中关闭 **渲染（Rendered）** 可查看逐行差异。
- **恢复（Restore）** 这个版本（仅限可读写项目文件夹中的文件）。恢复前会先把当前文件存为 **恢复前（Before restore）** 版本，随时可以撤销。
- 点 × **返回当前文件（Back to current file）**。

在文件标签页中查看某个版本时，底栏右端的 **另存为…（Save as…）** 可以把这个版本的副本保存到任意位置。

## 实时上下文（Beta）

在 macOS 26 或更高版本上，工作台的 **实时上下文（Live context）** 卡片把麦克风和/或系统音频在本机转写成文字，供当前对话使用；只保存文字，不保存音频。Windows 版暂不提供。

- **开始**：选好 **麦克风（Microphone）** 和/或 **系统音频（System audio）**、说话的语言，点 **开始（Start）**。转写时显示计时和最近几秒的波形，可以暂停、继续和停止；同一时间只有一个对话在转写。在新会话页点 **开始**，Pine 会在输入框所选的项目里新建一个对话并开始转写。
- **识别说话人（Identify speakers）**：打开后，转写按“说话人 1”“说话人 2”等标注是谁在说话，模型在本机运行，标签会晚几秒出现。点击标签可以重命名或合并到另一个说话人；卡片“…”菜单中的 **说话人（Speakers）** 可以集中管理。
- **实时翻译**：打开翻译后，每句说完的话会在下方附上译文，目标语言默认是界面语言，可以在语言菜单中更改。翻译用的模型在 **Pine 设置（Pine Settings）→ 模型（Models）→ 实时翻译模型（Live translation model）** 中选择。
- **和智能体一起用**：你发的每条消息都会带上自上一条以来的新转写，智能体也可以自己翻阅更早的部分，直接问“他们在讨论什么”即可。让它“记一下这节课”时，它会先请你批准再开始转写，之后可以自行暂停、继续或停止。
- **删除**：卡片“…”菜单中的 **删除实时上下文（Delete live context）** 会永久删除这个对话的转写、说话人名称和译文，无法撤销。

> [!NOTE]
> 麦克风或系统音频权限没有打开时，卡片上会给出提示，点 **打开系统设置（Open System Settings）** 即可前往对应的隐私设置。不想让智能体用到实时上下文，可以在 **Pine 设置（Pine Settings）→ 智能体（Agent）→ 工具（Tools）** 中关闭 **实时上下文（Live Context）**。

## 文件预览

在文件树、会话或产出文件中点击文件，会以标签页打开预览。根据格式不同，预览提供 **渲染（Rendered）** / **文本（Text）** 视图、翻页、搜索、缩放、旋转、反色、工作表和图层切换，以及底栏最左端的 **用默认应用打开（Open with default application）**。

### 批注与详细信息卡片

文件标签页在前台时，右侧栏不显示会话的卡片，而是显示这个文件的卡片：可以批注的项目文件上方是 **批注（Comments）**，下方是 **详细信息（Details）**；其他文件只显示详细信息。右侧栏默认关闭，用预览底部的 **批注** 按钮（不能批注的文件显示为 **详细信息**）、标题栏的工作台按钮或 `Mod + Alt + B` 打开。

**详细信息** 列出类型、大小、修改和创建时间、位置，以及预览测得的编码、行数、尺寸、时长、页数、行列数，还有格式本身记录的信息，例如文档的标题、作者、应用和字数，照片的相机、拍摄时间和色彩模式，音视频的编码和标签，邮件的发件人和收件人，压缩包的条目。

### Markdown 图片查看

在 Markdown 文件的渲染视图中点击图片（或聚焦后按回车），窗口变模糊，图片放大到窗口中央。底部工具栏可以切换上一张 / 下一张、**适合窗口（Fit to window）**、缩小和放大；`Mod + 滚轮` 也能缩放，放大后可以拖动查看。点图片外面、关闭按钮或按 `Esc` 返回。

### 图片和视频的右键菜单

在文件预览中的图片或视频、放大的 Markdown 图片，或对话中的图片上右键，会显示系统菜单：可以拷贝图像、存储图像或视频、拷贝文件路径（网络图片是拷贝地址）、在访达中显示（Windows 上是文件资源管理器），macOS 上还可以共享。

### 音视频播放器

音频和视频用 Pine 自己的播放器播放：进度条（点击或拖动跳转）、播放 / 暂停、当前时间和总长、**评论此刻（Comment on this moment）**、**循环播放（Loop）**、**播放速度（Playback speed）**、静音和音量，视频还有 **画中画（Picture in picture）** 和全屏。快捷键见[快捷键](shortcuts.md)。

## 预览批注

在项目文件的预览里，可以对文件的某些部分写下修改意见，攒够了再一次发给会话。

### 能批注什么

| 方式 | 适用格式 |
| --- | --- |
| 选中文字 | 文本、代码、Markdown（文本或渲染视图）、HTML、Word 等文档（DOCX、DOC、ODT、RTF、Pages）、PDF、幻灯片（PPTX、PPT、Keynote）、EPUB 电子书、邮件（EML、MSG） |
| 选中单元格 | 电子表格（XLSX、Numbers）、CSV / TSV 等数据表、SQLite 表 |
| 框选区域 | 图片、PDF 页面、幻灯片、PSD、OFD、Typst、PostScript、draw.io、Mermaid 等图表、思维导图 |
| 时间段 | 音频和视频 |

### 怎么批注

- **文字和单元格**：选中后在浮动菜单中点 **批注（Comment）**，或按 `Mod + Alt + M`，输入意见。回车保存，`Shift + 回车` 换行，`Esc` 取消。
- **区域**：点预览底部的 **框选批注（Comment on area）**，在图片、页面或幻灯片上拖出一个框，`Esc` 取消。
- **时间段**：播放器里点 **评论此刻** 批注当前时间点；按住 `Shift` 在进度条上拖动，或在起点按 `I`、终点按 `O`，标出一段时间再批注。

批注过的文字以琥珀色高亮，单元格和区域以琥珀色框出，点击即可在右侧栏定位到那条批注。

### 管理和发送

- **批注** 卡片按文档顺序列出所有批注，每条显示位置（如“第 12 行”、“第 3 页”、“B2:D5”、“0:12–0:30”）、引用的原文和意见，可以编辑或删除。原文在文件改动后不复存在时，会标记为“原文已变化（Original text changed）”。
- 卡片底部的 **发送 N 条批注（Send N comments）** 列出项目里的会话标签页和新会话。选一个，批注就以批注附件的形式（文件、位置和意见）放进那个会话的输入框，并从预览中清除。
- **全部清除（Clear all）** 会先确认再删除。

> [!NOTE]
> 每个文件最多 50 条批注。批注只保存在内存中，发送或清除前一直有效，退出 Pine 后不会保留。
