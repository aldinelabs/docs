# 进阶配置

[使用 Pine](../using-pine.md) 讲了最基本的项目、会话和审批。这一组页面把 Pine 的可选功能和设置项逐一讲清楚：每一项做什么、默认是什么、在哪里打开。它们都不是必须的，需要时按主题查阅即可。

> [!NOTE]
> 文中 `Mod` 在 macOS 上是 `Cmd`，在 Windows 上是 `Ctrl`。界面文案写成「中文（English）」，与 Pine 的中文和英文界面对应。

## 按主题查找

- [设置详解](settings.md)：**Pine 设置（Pine Settings）** 里通用、外观、模型、智能体、自定义、项目管理各分区的每一个选项
- [审批与自动审核](approvals.md)：四种审批模式、自动审批路径、审批卡片上的信息，以及哪些操作永远需要你确认
- [会话进阶](sessions.md)：追加要求、引用与追问、附件、中途回答、交互式回答、上下文与费用、子会话，以及让智能体整理会话和项目
- [工作台与文件预览](workbench.md)：右侧工作台的各个面板、文件详情、预览批注、音视频播放器和图片查看
- [自动化、Skills 与 MCP](automations.md)：无人值守的自动化任务、可复用的 Skills，以及接入外部工具的 MCP 服务器
- [远程控制](remote.md)：浏览器访问、经 Aldine 配对手机或其他设备、保持电脑唤醒、后台运行与托盘菜单
- [微信远程](wechat.md)：用自己的微信给 Pine 派任务，以及微信里可用的全部命令
- [快捷键](shortcuts.md)：所有键盘快捷键

## 设置在哪里

点标题栏的齿轮图标打开 **Pine 设置（Pine Settings）**。左侧是分区列表（手机上先显示分区列表）：

| 分区 | 主要内容 | 详见 |
| --- | --- | --- |
| **通用（General）** | 语言、货币、Monet 模式、完成提示、通知、快速提问、后台运行、诊断日志 | [设置详解](settings.md) |
| **外观（Appearance）** | 配色模式、默认颜色主题、工作光效、侧栏材质、文档反色 | [设置详解](settings.md) |
| **模型（Models）** | 模型目录刷新、标题生成、审批、图像与视频生成、Decisions 初筛模型 | [设置详解](settings.md) |
| **智能体（Agent）** | 交互式回答、中途回答、自动审批路径、上下文压缩、网络工具、大致位置 | [设置详解](settings.md) |
| **自定义（User profile）** | 昵称、人称代词、语言风格、技术背景、个人细节、自定义指令 | [设置详解](settings.md) |
| **项目管理（Projects）** | 所有项目及其数据占用，清理临时文件和附件 | [设置详解](settings.md) |
| **远程控制（Remote control）** | 保持唤醒、经 Aldine 配对设备、浏览器访问、微信 | [远程控制](remote.md)、[微信远程](wechat.md) |

自动化、Skills 和 MCP 服务器不在设置对话框里，而是在左侧栏顶部的 **更多功能（More）** 菜单中，见[自动化、Skills 与 MCP](automations.md)。
